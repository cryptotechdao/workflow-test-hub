# Workflow Test Hub

Lightweight static dashboard for API requests, webhooks, AI endpoints, health checks and JSON.

## GitHub Pages
Create a repository, upload the 3 site files, then Settings → Pages → Deploy from branch → main/root.

URL: https://YOUR-USERNAME.github.io/workflow-test-hub/

## Cloudflare Pages
Upload/connect this folder and Cloudflare will provide a `*.pages.dev` address.

Note: browser CORS restrictions can block APIs. Do not use frontend fields for production secrets.
